# 👑 VIP Numbers Morocco - Sales System

هذا المجلد يحتوي على النظام الكامل لإدارة مبيعات أرقام VIP عبر WhatsApp والموقع الإلكتروني.

## 📁 محتويات المجلد:
- **index.html**: الموقع الإلكتروني (Landing Page) - تم تحديثه ليقرأ البيانات مباشرة من `catalog.json`.
- **whatsapp_bot.py**: كود البوت الذي يدير الطلبات والتحكم في المخزون (Inventory) عبر WhatsApp.
- **catalog.json**: قاعدة البيانات التي تحتوي على الأرقام، أثمنتها، وحالتها (Available/Sold).
- **api_keys.json**: يحتوي على مفاتيح الـ API (DeepSeek, WhatsApp, etc.).
- **netlify.toml**: إعدادات خاصة برفع الموقع على Netlify.

## 🚀 كيف يعمل النظام الآن؟
1. **الموقع (Static):** الموقع الآن مستقل تماماً عن سيرفر بايثون. يمكن رفعه على Netlify وسيقوم بعرض الأرقام الموجودة في `catalog.json` تلقائياً.
2. **البوت (Management):** عند تشغيل `whatsapp_bot.py` في حاسوبك، يمكنك التحكم في الأرقام عبر إرسال أوامر من رقم الأدمن الخاص بك إلى رقم الواتساب المرتبط بالبوت.

## 🤖 أوامر الأدمن (WhatsApp Commands):
- `!sold [الرقم]`: لوضع علامة "تباع" على الرقم (سيختفي من الموقع فوراً عند تحديث الملف).
- `!add [فئة] [الرقم] [الثمن]`: إضافة رقم جديد (مثال: `!add diamond 0600000000 150 DH`).
- `!price [الرقم] [الثمن الجديد]`: تغيير ثمن رقم موجود.
- `!delete [الرقم]`: حذف الرقم نهائياً من القائمة.
- `!image`: توليد صورة ترويجية للأرقام المتوفرة حالياً.

## 🛠 التكنولوجيا المستخدمة:
- **AI Engine:** DeepSeek Official API (V3) - سريع وذكي جداً في فهم الدارجة.
- **Frontend:** HTML/CSS/JS (Static Fetch).
- **Backend:** Python Flask (For Management & Webhooks).

## 🌍 الرفع على Netlify:
لأنه تم تحويل الموقع إلى Static، أسهل طريقة هي:
1. افتح حسابك في Netlify.
2. اسحب مجلد `VIP_BOT_FINAL` بالكامل وألقه (Drag & Drop) في نافذة الرفع.
3. الموقع سيعمل 100% بدون أي إعدادات إضافية.
